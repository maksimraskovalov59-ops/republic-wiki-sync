# Исправить слипание строк и абзацев в статьях

## Проблема

В рендере Markdown у абзацев, списков и заголовков нет вертикальных отступов: класс `prose` в проекте ничего не задаёт (плагин типографики не подключён), а собственные стили в `src/components/Markdown.tsx` задают только размер и цвет текста. Плюс одиночный перенос строки в Markdown по стандарту склеивается в один абзац, поэтому текст выглядит как сплошная стена.

## Что сделаю

1. Добавить вертикальные отступы в `src/components/Markdown.tsx`:
   - абзацы: отступ снизу (примерно 1em), сохранив текущий `leading-7`;
   - списки, цитаты, таблицы, изображения, блоки кода: свои отступы сверху/снизу;
   - заголовки H2/H3: увеличенный отступ сверху и небольшой снизу.
2. Включить перенос по одиночному Enter (плагин `remark-breaks`), чтобы поведение совпадало с ожиданием автора: одна пустая строка — новый абзац, один Enter — перенос строки.
3. Применить те же стили в превью редактора (используется тот же компонент `Markdown`, отдельных правок не потребуется — проверю визуально).
4. Проверить страницу статьи и превью редактора в браузере: отступы между абзацами видны, вёрстка на мобильном не ломается.

## Технические детали

- Файл: `src/components/Markdown.tsx` — только классы Tailwind + добавление remark-плагина.
- Новая зависимость: `remark-breaks` (маленький, совместим с текущим `react-markdown` + `remark-gfm` + `rehype-sanitize`).
- База данных и содержимое статей не меняются.
