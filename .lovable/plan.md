# Скриншоты всех страниц вики для инвесторов

Соберу набор чистых скриншотов каждой страницы сайта и положу их в папку с файлами, откуда их можно скачать.

## Что будет на скринах

Публичные страницы:
- Главная (`/`)
- Все статьи (`/articles`)
- Поиск (`/search`) — с введённым запросом, чтобы видны были результаты
- Изменения (`/recent`)
- Категория (`/category/<первая категория>`)
- Статья (`/article/pravila`)
- Профиль игрока (`/user/TheHapPpyONE`)
- Вход/регистрация (`/auth`)

Страницы под входом (со восстановленной сессией администратора):
- Кабинет (`/cabinet`)
- Редактор статьи (`/editor`)
- Админка (`/admin`)

Для каждой страницы — desktop-скрин (1600×1000, широкий экран) и mobile-скрин (390×844), чтобы показать адаптивность.

## Результат

Файлы вида `investors/desktop-01-home.png`, `investors/mobile-01-home.png` в папке документов, плюс краткий список «файл → страница» в ответе. Дополнительно соберу одну сводную контактную страницу-коллаж desktop-скринов для быстрого обзора.

## Технические детали

- Playwright (headless Chromium) по локальному dev-серверу `http://localhost:8080`, скрипт во временной папке.
- Сессия для приватных страниц восстанавливается из `LOVABLE_BROWSER_SUPABASE_*` (localStorage + cookies), без ввода паролей.
- Перед снимком ожидание загрузки данных, скролл вверх, пауза для завершения анимации фоновых кубиков.
- Изменений в коде проекта не будет — только генерация изображений.
