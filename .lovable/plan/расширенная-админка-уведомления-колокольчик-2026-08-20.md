# Расширенная админка + уведомления (колокольчик)

## 1. Модерация участников

В блоке «Участники и права» у каждого участника появляются действия:

- **Мут** — участник читает вики, но не может создавать статьи, отправлять правки и писать комментарии. В интерфейсе он видит понятную плашку вместо форм.
- **Полный бан** — аккаунт не может войти на сайт; при попытке входа показывается сообщение о блокировке с причиной.
- **Разблокировать** — снимает мут или бан.
- При блокировке админ указывает причину и (опционально) срок: «навсегда» или до даты.
- Создателя (`TheHapPpyONE`) и самого себя заблокировать нельзя; админа может блокировать только другой админ.
- Список показывает статус блокировки, причину и кто заблокировал.

## 2. Действия над статьями

Новый блок «Управление статьями» в `/admin` с поиском по названию:

- обнулить просмотры у одной статьи;
- обнулить просмотры у всех статей (с подтверждением);
- снять с публикации (вернуть в черновик) / опубликовать снова;
- удалить статью (с подтверждением);
- сменить тип «статья/новость» и закрепить/открепить в популярных;
- удалить комментарий (кнопка удаления у комментариев на странице статьи для админа уже есть — добавлю в админку список последних комментариев с удалением).

## 3. Журнал действий администраторов

Все админские действия (роль, блокировка, удаление, обнуление просмотров, модерация правок) пишутся в журнал. Отдельный блок «Журнал действий» в `/admin` — кто, что и когда сделал. Это защита от спорных ситуаций.

## 4. Колокольчик и уведомления

В шапке рядом с кабинетом появляется колокольчик со счётчиком непрочитанных. По нажатию — выпадающий список последних уведомлений со ссылками на нужную страницу, кнопки «прочитать» и «прочитать все». Полный список — в кабинете.

События, о которых уведомляем:

- статью одобрили / отклонили (с причиной);
- правку приняли / отклонили;
- новый комментарий к вашей статье;
- изменилась ваша репутация (плюс/минус от участника);
- вам выдали или сняли админку;
- вас заблокировали / разблокировали.

Уведомления приходят «сразу» — список обновляется в реальном времени, без перезагрузки страницы.

## Техническая часть

**База (одна миграция):**

- `profiles`: `muted_until timestamptz`, `banned_until timestamptz`, `block_reason text`, `blocked_by uuid` (или отдельная таблица `user_blocks` — использую поля на `profiles` + запись в журнал, чтобы не плодить джойны). Обновить `protect_profile_fields()`, чтобы обычный пользователь не мог менять эти поля сам.
- Хелперы `public.is_muted(uuid)`, `public.is_banned(uuid)` (SECURITY DEFINER, EXECUTE только `authenticated`) и подключение `NOT public.is_muted(auth.uid())` в INSERT-политики `articles`, `edit_suggestions`, `comments`, `user_reputation_votes`.
- `admin_audit_log (id, actor_id, actor_name, action, target_type, target_id, details jsonb, created_at)` + GRANT + RLS: SELECT/INSERT только админам.
- `notifications (id, user_id, kind, title, body, link, read_at, created_at)` + GRANT + RLS: чтение/обновление (пометка прочитанным)/удаление только своих строк; вставка — через `service_role`/триггеры.
- Триггеры для авто-уведомлений: новый комментарий к статье автора, изменение `user_reputation_votes`, изменение `user_roles`. Уведомления по модерации статей и правок создаются в серверных функциях.
- Realtime на `notifications` для мгновенного колокольчика.

**Код:**

- `src/lib/wiki-admin.server.ts`: `logAdminAction`, `notify`, `assertNotBlocked`, проверки создателя.
- `src/lib/wiki.functions.ts`: `setUserBlock`, `unblockUser`, `adminListArticles`, `resetArticleViews`, `resetAllViews`, `setArticleStatus`, `deleteArticle`, `adminListComments`/`deleteComment`, `listAuditLog`, `listNotifications`, `markNotificationsRead`. Все — через `requireSupabaseAuth` + проверка роли админа; в `approve/rejectEditSuggestion` и модерацию статей добавляю создание уведомлений и запись в журнал.
- Бан на входе: проверка `banned_until` в `src/routes/_authenticated/route.tsx`-совместимом виде — публичная серверная функция `getBlockStatus` + плашка на `/auth` и авто-выход; мут — плашка в редакторе, форме правок и комментариях.
- Новый компонент `src/components/NotificationsBell.tsx` (поповер + счётчик + realtime-подписка), встраивается в `src/components/SiteHeader.tsx`; список уведомлений также в `src/routes/_authenticated/cabinet.tsx`.
- `src/routes/_authenticated/admin.tsx`: новые блоки «Управление статьями», «Журнал действий», расширенный блок участников.
