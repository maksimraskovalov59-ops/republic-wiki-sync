# Главная: порядок блоков на телефоне + оживить низ страницы

## 1. Мобильный порядок

Сейчас на телефоне колонки идут в порядке разметки: новости → поиск → популярные статьи. Поиск и логотип должны быть первыми.

Новый порядок на мобильном (до `lg`):

1. Логотип REPUBLICMC + строка поиска + описание
2. Популярные статьи
3. Новости

На десктопе (`lg` и выше) три колонки остаются как сейчас: новости слева, центр с поиском, популярное справа. Меняется только визуальный порядок на узких экранах, содержимое и ссылки не трогаем.

Дополнительно на мобильном: убрать лишний верхний отступ у центральной секции, уменьшить логотип, чтобы поиск попадал в первый экран. И логотип на мобильных обрезается, на влезает в экран (Верхняя строка, где также гамбургер меню)

## 2. Оживить страницу

Низ главной пустой. Добавляем два уровня:

- **Фоновые летающие кубики.** Расширяем существующий пиксельный фон: вместо статичных мерцающих точек — медленно дрейфующие «кубики» разного размера, лёгкое вращение и всплытие, разные скорости и задержки. Полностью пассивные, не перехватывают клики, приглушённые, чтобы не мешали чтению. Уважаем `prefers-reduced-motion` — при включённой настройке движение отключается.
- **Секция под тремя колонками** во всю ширину, чтобы низ не выглядел обрезанным: короткий блок «Разделы вики» с плитками-ссылками на существующие разделы (Все статьи, Изменения, Правила, Карта, Сообщество) и строкой статистики (сколько статей, сколько просмотров) — данные берём из уже загружаемых данных главной, без новых запросов, если их достаточно; иначе показываем только плитки.

Стиль — существующие токены темы и `surface-card`/glow-классы, чтобы все палитры (тёмная, светлая, премиум) работали без правок.

## Технически

- `src/routes/index.tsx`: колонкам задать `order-*` классы для мобильного и `lg:order-*` для десктопа; добавить нижнюю секцию после `main`-грида (или как элемент с `lg:col-span-3`).
- `src/components/PixelField.tsx`: расширить набор фигур, добавить кубики с CSS-анимацией дрейфа/вращения.
- `src/styles.css`: добавить keyframes для дрейфа кубиков и правило `@media (prefers-reduced-motion: reduce)`.
